# Publish your portfolio with GitHub Pages

## Website repository
1. Sign in to GitHub as **Muskaan1010**.
2. Create a **public** repository named exactly `Muskaan1010.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Commit to the `main` branch.
5. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

Your site URL will be: https://Muskaan1010.github.io/

## GitHub profile README
1. Create a separate **public** repository named exactly `Muskaan1010`.
2. Add the supplied `README.md` to its root and commit.
3. GitHub will display it on your profile because the repository name matches your username.

## Before publishing
- Replace the placeholder project links with the actual public repository URLs.
- The portfolio bundle includes your resume in `assets/` if the previous PDF was available during packaging. To add it manually, copy your final PDF to `assets/Muskaan_M_D_Resume.pdf`.
- Confirm the internship metrics (87% test accuracy and 12% lower forecast error) and be ready to explain how they were measured.
- Add tools/methods such as Jira, Figma, Agile, Scrum, PRDs, or user stories only after you have used or studied them.
- Google Fonts are loaded online. The site itself is static and requires no build tools or package installation.

## Local preview
Open `index.html` in a browser. Edit `index.html` for content, `styles.css` for appearance, and `script.js` for interactions. Commit changes to `main` to publish updates.
